========================================
HOW TO USE THE MIGRATION TOOLS
========================================

STEP 1: Choose Your Migration Method
-------------------------------------
Option A (Recommended): Use the automated script
   ./migrate-to-phase-ii.sh

Option B (Quick): Use the quick setup
   ./quick-migrate.sh

STEP 2: Handle Phase-II README (Optional)
------------------------------------------
If phase-ii has a README you want to preserve:
   - The script will try to back it up automatically
   - If authentication fails, download it manually
   - Replace README.md with the phase-ii version
   - Commit: git add README.md && git commit -m "Preserve phase-ii README"

STEP 3: Push to Phase-II
-------------------------
You'll need authentication (Personal Access Token or SSH)

Push commands:
   git push phase-ii migration-from-project-01:main --force
   git push phase-ii --tags

STEP 4: Verify Migration
-------------------------
Clone phase-ii and verify:
   git clone https://github.com/chartchai-class/the-social-anti-fake-news-system-phase-ii-thejobless.git
   cd the-social-anti-fake-news-system-phase-ii-thejobless
   git log --oneline | wc -l  # Should show 44 commits
   git tag -l  # Should show: Final-version, Version-1.0
